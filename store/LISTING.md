## Category
Productivity

## Description
On claude.ai, the dictation mic disappears the moment you type or paste anything into the message box. Paste a link, type a first line, and there's no way to keep going by voice.

Sticky Mic keeps a mic button next to Send, so you can switch to dictation at any point while writing a message.

• Uses Claude's own dictation: Sticky Mic presses claude.ai's built-in Dictate button, so you get the same transcription quality as usual.
• No duplicate buttons: once Claude shows its own mic, Sticky Mic steps aside.
• Private by design: no permissions, no data collection, no network requests.
• Lightweight: one small script that runs only on claude.ai.

Works in Chrome and Edge on claude.ai. The Claude desktop app does not support extensions.

Unofficial. Not affiliated with, endorsed by, or sponsored by Anthropic. Claude is a trademark of Anthropic.
